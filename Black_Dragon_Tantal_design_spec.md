# ТЗ / Описание дизайна: «Black Dragon · Tantal»

Ниже — полное текстовое описание визуального дизайна веб-страницы (HTML/CSS/JS), достаточное для того, чтобы воссоздать его с нуля без исходного файла. Все цвета, размеры, шрифты и логика анимации указаны точно.

---

## 1. Общая концепция

Тёмная, минималистичная лого-заставка на всю страницу с эффектом «роя светлячков» (светящихся частиц), непрерывно кружащих вокруг подсвеченного слова. Стиль — премиальный, мистический, атмосфера «магического логотипа».

---

## 2. Страница и разметка

- Фон всей страницы: `#0a0a0a` (почти чёрный).
- Базовый шрифт: Arial, sans-serif.
- Контент центрирован по горизонтали и вертикали (flex: `justify-content: center; align-items: center; min-height: 100vh`).
- Отступы страницы: `padding: 2rem 1rem`.
- Прокрутка и выделение текста отключены (`overflow: hidden`, `user-select: none`).
- Внутри — контейнер шириной до `750px`, полностью прозрачный: без фона, без рамки, без тени — просто ограничивает максимальную ширину текстового блока.
- Текстовый блок внутри контейнера выровнен по левому краю, при этом сам блок центрирован на странице (inline-block + text-align: center у родителя).

## 3. Текстовый блок (3 строки)

### 3.1 Строка 1 — заголовок «BLACK DRAGON»
- Текст: `BLACK DRAGON`, заглавными буквами (text-transform: uppercase).
- Шрифт: serif — Georgia, затем Times New Roman как фолбэк.
- Размер: адаптивный `clamp(2rem, 5vw, 3.6rem)` (≈32px–57.6px в зависимости от ширины экрана).
- Насыщенность: 700 (жирный).
- Межбуквенный интервал: `0.05em`.
- Цвет: `#e6e6fa` (светло-лавандовый / бледно-сиреневый).
- Без свечения и теней — плоский светлый текст.
- Небольшой отступ снизу (padding-bottom: 6px) под линию.

### 3.2 Световая «блик-линия» под заголовком
- Тонкая горизонтальная полоса, высота `2px`, ширина 100% от блока заголовка, накладывается вплотную под текст (`margin-top: -2px`).
- Линейный градиент слева направо (это статичная картинка блика, не обязательно анимировать, но можно):
  - 0%–30% — полностью прозрачный `rgba(200,200,220,0)`
  - 45% — светло-сиреневый `#aaaaee`
  - 50% (центр, пик яркости) — чистый белый `#ffffff`
  - 55% — снова `#aaaaee`
  - 70%–100% — прозрачный `rgba(200,200,220,0)`
- Прозрачность всей линии: `opacity: 0.7`.
- Вокруг линии — мягкое свечение: `drop-shadow(0 0 6px rgba(200,200,220,0.5))`.
- Линия не кликабельна (`pointer-events: none`).

### 3.3 Строка 2 — подзаголовок «Project Midas»
- Расположена под линией, отступ сверху `margin-top: 0.3em`.
- Выравнивание текста — по правому краю.
- Шрифт: тот же serif (Georgia / Times New Roman), курсивный (`font-style: italic`).
- Размер: адаптивный `clamp(1.2rem, 2.5vw, 1.8rem)` (≈19px–29px).
- Насыщенность: 400 (обычная).
- Межбуквенный интервал: `0.03em`.

**Слово «Project»:**
- Цвет: `#e6e6fa` (тот же светло-лавандовый, что и заголовок).
- Курсив, как у всей строки.

**Слово «Midas» (акцентный элемент, класс типа `.tantal`):**
- Насыщенность: 700 (жирный).
- Стиль: не курсив (`font-style: normal`, переопределяет курсив родителя).
- Межбуквенный интервал: `0.06em`.
- Цвет: управляемая переменная, по умолчанию `#e6e6fa` (тот же лавандовый). Можно вынести как CSS-переменную `--master-color`, чтобы легко менять весь акцентный цвет одной точкой.
- Свечение (text-shadow), 4 слоя одного и того же цвета (`--master-color`) с уменьшающейся интенсивностью:
  1. blur 15px, интенсивность цвета 60%
  2. blur 30px, интенсивность цвета 40%
  3. blur 45px, интенсивность цвета 20%
  4. blur 60px, интенсивность цвета 0% (практически невидимый внешний слой, для мягкого перехода)
- Эффект: слово выглядит как источник мягкого магического неонового свечения.

## 4. Анимация частиц (рой «светлячков») — ключевой эффект

Поверх всей страницы — HTML5 `<canvas>` на весь экран (`position: fixed; top:0; left:0; width:100%; height:100%; z-index:10; pointer-events:none`), на котором JS рисует и анимирует облако светящихся точек-частиц, кружащих вокруг слова «Midas».

### 4.1 Параметры системы частиц
| Параметр | Значение | Описание |
|---|---|---|
| Цвет частиц | `#e6e6fa` | тот же лавандовый, что и свечение слова Midas |
| Количество частиц | 50 | одновременно на экране |
| Размер частицы | 0.2–0.8 | случайный радиус (в px canvas) |
| Свечение частицы (shadowBlur) | 4px | того же цвета |
| Базовая скорость | 0.3 | множитель |
| Ускорение на старте полёта | 1.5 | быстрее в начале движения ("вылет") |
| Замедление к финишу | 0.5 | плавно тормозит к концу ("посадка") |
| Длительность одного перелёта | 4500–9500 мс | случайная на каждую частицу |
| Диапазон удаления от контура слова | 0–15px | частицы держатся близко к рамке слова |
| Амплитуда изгиба дуги | 27px | степень "кривизны" траектории |
| Режим непрерывности | включён | частицы никогда не исчезают/не появляются заново — сразу продолжают полёт новой дугой |
| Прозрачность (альфа) | фиксированная 0.8 | без мерцания/пульсации |

### 4.2 Логика движения (как это должно быть реализовано)
1. Каждая частица летит не по прямой, а по **квадратичной кривой Безье** (3 точки: старт P0, контрольная точка P1, финиш P2) — то есть по плавной дуге.
2. Контрольная точка P1 = середина отрезка P0–P2, смещённая в случайном направлении на случайное расстояние (20–100% от амплитуды 27px) — придаёт каждой дуге лёгкий естественный изгиб.
3. Обе точки (старт и финиш) генерируются как случайные точки **по периметру прямоугольника**, описывающего слово «Midas», отступая наружу на 0–15px — частицы облетают именно контур слова, не залетая внутрь и не улетая далеко.
4. Скорость вдоль дуги не постоянна: в начале движения (вылет от точки) — ускорена (×1.5), к концу (подлёт к следующей точке) — замедлена (×0.5), переход между этими состояниями плавный, по косинусоидальной интерполяции.
5. По достижении конца дуги частица **не исчезает**, а сразу строит новую дугу, начиная ровно с текущей точки, снова огибая слово «Midas» — рой существует непрерывно и бесконечно, без "мигания"/появления заново.
6. При изменении размера окна или прокрутке страницы позиция и размеры слова «Midas» пересчитываются заново, чтобы рой корректно следовал за словом.
7. Каждая частица рисуется как залитый круг (`ctx.arc`) с применённым свечением (shadowColor/shadowBlur того же лавандового цвета) и фиксированной прозрачностью 0.8.

### 4.3 Итоговое визуальное впечатление
На почти чёрном фоне — строгий serif-заголовок «BLACK DRAGON» с тонкой световой полосой-бликом под ним (переход прозрачный → сиреневый → белый в центре → сиреневый → прозрачный). Ниже, выровненная по правому краю — курсивная подпись «Project Midas», где слово «Midas» является светящимся магическим центром композиции: оно светится мягким многослойным лавандовым ореолом, а вокруг него по контуру непрерывно и плавно, дугообразными траекториями с ускорением-замедлением, кружит облако из ~50 крошечных светящихся частиц — как рой светлячков или магических искр вокруг заряженного объекта.

## 7. Технические заметки для реализации в Cursor

- Слово «Midas» и заголовок должны использовать **serif**-шрифт (Georgia/Times New Roman), остальное — Arial/sans-serif по умолчанию у body.
- Анимация частиц реализуется через `<canvas>`, поверх DOM, с requestAnimationFrame-циклом.
- Позиция и размер прямоугольника слова «Midas» (`getBoundingClientRect()`) — опорная точка для генерации траекторий частиц; должна пересчитываться при resize/scroll.
- Весь дизайн адаптивный (используется `clamp()` для размеров шрифта), должен корректно масштабироваться на мобильных экранах.
- Цвет акцента (`#e6e6fa`) рекомендуется вынести в CSS-переменную для лёгкой смены темы.
